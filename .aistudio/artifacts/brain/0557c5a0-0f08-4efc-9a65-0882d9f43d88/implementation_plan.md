# Project Scoping & Unified IDE-Browser Integration

Streamline workspace and project isolation across the Inspector Panel, Quick Panel, and Terminal suggestion chips. Ensure projects contain only their own dedicated files, tabs, chats, extensions, and bots, enable seamless project selection/unselection in Terminal, and empower AI to automatically edit and inspect files across the IDE and browser preview.

### User Review & Critical Decisions

> [!IMPORTANT]
> The following user preferences were confirmed during Phase 1 clarification:
> - **Project Scope Integrity**: Projects in the Quick Panel and Inspector strictly encapsulate only their related files, tabs, chats, extensions, and bots. Project files can be created, generated by AI, or imported from the device.
> - **All Files vs. Project Files**: The general "Files" inspector continues to display all workspace files, while the "Project" view isolates project-specific resources.
> - **Terminal Project Suggestion Chip**: Users can select any project to directly switch chat context into that project, with the critical addition of an **unselect/clear** affordance to return to the global root directory.
> - **AI Execution Mode**: Full auto-edit and inspect mode—AI commands directly write/update project files, synchronize with the IDE code editor, and provide live browser preview.

- **Confirmed Decision 1**: Project model extended with dedicated `extensions: List<String>` and `bots: List<String>` alongside `files`, `tabs`, and `chats`.
- **Confirmed Decision 2**: Terminal directory suggestion chip includes an explicit unselect action and dropdown clear option to switch between project-scoped chats and global root.
- **Confirmed Decision 3**: AI file changes auto-update the active IDE editor buffer and register for instant browser preview.

### 1. Overview & Core Concept

Currently, project files and global workspace files can be conflated in the navigation panels, and the Terminal suggestions chip allows selecting directories/projects without an effortless way to unselect back to root. Furthermore, chats and AI tools need strict project-scoping so that conversations, suggested actions, and file modifications directly alter the chosen project.

This update introduces:
1. **Isolated Project Views in Quick Panel & Inspector**: Within any project, users see sub-tabs for **Files** (only project files, with Add / AI Create / Device Import buttons), **Tabs** (browser & IDE tabs), **Chats** (project-specific chat logs), **Extensions** (project-active extensions), and **Bots** (project-assigned agents).
2. **Global Workspace Files Inspector**: A dedicated view in the Inspector Panel showing the complete filesystem tree without project restrictions.
3. **Smart Terminal Suggestion Chip with Unselect**: An interactive chip showing the active target directory or project. Tapping opens a selector with project badges, plus an immediate 'X' button and 'Unselect (Global Root)' option to clear scope.
4. **Project-Scoped Terminal Chat**: Selecting a project immediately pulls up that project's chat log and scopes AI context to its files and tabs.
5. **Full Auto-Edit & Live Preview Integration**: Terminal AI commands directly modify project files, refresh open IDE editor tabs, and display preview affordances to view changes in the browser.

### 2. User Experience & Visual Design

#### Key User Flows

1. **Viewing & Managing Project Resources**:
   - The user opens the Quick Panel or Inspector Panel Project tab.
   - The user selects a project: clean pill navigation toggles between **Files**, **Tabs**, **Chats**, **Extensions**, and **Bots**.
   - Under **Files**, only project files are listed. The user can tap `+ Add File`, `+ AI Generate`, or `+ Import from Device` (using Android's photo/file picker).
   - Under **Tabs**, active web URLs and source file tabs for that project are listed with one-tap switching.
   - Under **Chats**, all historical prompts and AI exchanges related to that project are displayed.

2. **Selecting and Unselecting Project in Terminal**:
   - In the Terminal screen, above the prompt bar, the target chip reads `Target: [Project Name]` with a cyan badge.
   - A distinct `X` (close/unselect) button on the chip allows instantaneous clearing back to `Root (~)`.
   - In the dropdown menu, the first item is `Clear Selection / Global Root (~)`, followed by all saved projects with project folder icons.
   - When a project is selected:
     * Terminal displays a banner: `Active Project: [Project Name] • [N] files • [M] tabs`.
     * Chat history filters to that project's conversation thread.
     * Quick suggestion chips automatically adapt to the project's file types (e.g. `Run main.kt`, `Preview index.html`, `Add API Route`).

3. **AI File Modifications with IDE & Browser Preview**:
   - The user asks AI in Terminal to "Create an About page" or "Refactor Calculator logic".
   - AI auto-creates or updates the file directly in the project directory and records it in the project's file list.
   - The IDE workspace editor immediately opens the updated file in an editor tab.
   - A success card in Terminal provides direct action buttons: `[Open in Editor]` and `[Live Browser Preview]`.

#### Visual Identity & Styling
- **Color Palette**: Dark Xcode theme matching existing palette:
  * Primary Surface: `#0B0E14` / `#0F1523`
  * Project Cyan: `#38BDF8` with `#00E5FF` glow accents
  * Accent Amber (Inspector): `#F59E0B`
  * Success Emerald (File modifications): `#10B981`
  * Text Primary: `#F1F5F9`, Muted: `#94A3B8`
- **Component Geometry**: Rounded pill chips (`17.dp`), crisp border strokes (`1.dp` solid `#233554`), and clear visual status indicators.
- **Accessibility & Touch Targets**: Minimum 48dp touch targets for unselect chips and dropdown menu items.

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: Explicit Project Model Extension (`extensions` & `bots`)**
  * *Chosen Approach*: Add `extensions: List<String>` and `bots: List<String>` to `QuickMenuProject` with backward-compatible JSON serialization.
  * *Why*: Enables each project to remember which extensions (linters, formatters, live preview) and agent personas are assigned to it, satisfying the user's explicit requirement.
  * *Alternatives Considered*: Storing bot assignments in a separate global map, which would desynchronize when projects are exported or deleted.

- **Decision 2: Terminal Target Chip Dual-Interaction (Dropdown + Instant Unselect)**
  * *Chosen Approach*: The suggestion chip contains the clickable label that opens the project selector, alongside a dedicated trailing close icon (`Icons.Rounded.Close`) that unselects immediately in one tap.
  * *Why*: Solves the user's pain point ("currently we can directory can select but not unselected it") with zero friction.

- **Decision 3: Dual File Access in Inspector**
  * *Chosen Approach*: Inspector Panel features both `PROJECT` (project-scoped tabs, files, chats, extensions, bots) and `FILES` (workspace-wide filesystem tree).
  * *Why*: Provides quick access to project-only assets while preserving full-system inspection capabilities.

#### Data Model & State Changes
1. **`QuickMenuProject`**:
   - `id: String`, `name: String`, `description: String`
   - `tabs: List<String>`
   - `files: List<String>` (filtered, project-specific paths)
   - `chats: List<String>` (chat session keys or message IDs)
   - `extensions: List<String>` (extension IDs e.g. "prettier", "eslint")
   - `bots: List<String>` (bot personas e.g. "coder", "debugger", "architect")

2. **`BrowserViewModel`**:
   - `selectedProjectTarget: MutableStateFlow<QuickMenuProject?>` (null represents Root / Unselected)
   - Methods: `selectProjectTarget(QuickMenuProject?)`, `clearProjectTarget()`, `addFileToProject(projectId, filePath)`, `saveProjectChat(projectId, message)`
   - `applyAiProjectFileChange(projectId, filename, content, openInEditor, previewInBrowser)`

3. **`SuggestionsComponents.kt`**:
   - Update `SuggestionChipsBar` target chip to display project name when active, with an instant `X` unselect icon.
   - Update `DropdownMenu` to list "Clear / Global Root (~)" as item 0, followed by all saved projects.

4. **`XcodeInspectorPanel.kt` & `QuickMenuCard.kt`**:
   - Update project detail accordion/tabs to show only project-related files with `+ Add`, `+ AI Create`, and `+ Device Import`.
   - Provide sub-tabs for Files, Tabs, Chats, Extensions, and Bots.
